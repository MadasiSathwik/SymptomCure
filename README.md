# 🌿 Symptom Cure (Symptom-Green)

🚀 An AI-powered herbal remedy recommendation platform that provides natural treatment suggestions based on user symptoms, combining traditional medicine knowledge with modern technology.

---

## 📌 Overview

Symptom Cure is an intelligent healthcare assistant designed to analyze user symptoms and recommend suitable herbal remedies. The system focuses on delivering safe, reliable, and data-driven suggestions, including dosage, severity, and precautions for different user groups such as children, elderly, and pregnant individuals.

This project aims to make healthcare more accessible by leveraging AI and structured datasets.

---

## ✨ Features

* 🔍 Symptom-based disease identification
* 🌱 Herbal remedy recommendation system
* 📊 Severity-based analysis of conditions
* ⚠️ Safety guidelines (children, elderly, pregnancy)
* 💊 Dosage and side effects information
* 🧠 Data-driven decision-making system
* 🌐 Simple and user-friendly interface

## ⚙️ How It Works

1. User inputs symptoms
2. System processes and maps symptoms to possible conditions
3. Matches conditions with herbal remedies dataset
4. Returns:

   * Recommended remedies
   * Dosage instructions
   * Side effects
   * Safety precautions

## 🚀 Getting Started

### 🔧 Prerequisites

* Node.js / Python installed
* MongoDB (if used)

### ▶️ Installation

# Clone the repository

git clone https://github.com/MadasiSathwik/SymptomCure.git

# Navigate to project folder

cd symptom-cure

# Install dependencies

npm install

# or

pip install -r requirements.txt

---

### ▶️ Run the Project

# Start backend

npm start

# or

python app.py

# Start frontend

npm run dev
